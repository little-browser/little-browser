# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through GitHub's private vulnerability
reporting: open the **Security** tab of
[github.com/little-browser/little-browser](https://github.com/little-browser/little-browser) and choose
**Report a vulnerability**.

Include: affected version and platform, steps to reproduce, and impact. We aim to acknowledge within
3 working days.

## Chromium vulnerabilities

Bugs in upstream Chromium should be reported to the Chromium project. We ship Chromium security
releases within days of upstream; see the release notes for the Chromium version in each build.

## Supported versions

Only the latest release on each platform receives security fixes.
