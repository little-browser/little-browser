安静的网络，是什么样的

作者 Mara Lindqvist · 11月18日

大多数网页都想从你这里要点什么：一次点击、一次注册、你晚上多一点的时间。安静的网络什么都不要。它是那种开头就是食谱的食谱，是那种直接显示时间的时刻表。

它并不新。它是去掉那些让你不停滑动的设计之后剩下的东西，也是慢软件运动背后的想法：工具等着你，而不是追着你。

回头看时你最能体会。一个页面加载出来，说完该说的话，就让你离开，如今这几乎显得有些老派，却莫名让人安心。

Shift+点击链接，不离开当前页面就能看一眼。

慢软件

等着你的软件

慢软件不是说运行得慢。它指的是只做一件事、你做事时不打扰你、也从不编造理由让你回来的应用。

没有连续打卡，没有角标，没有红点。你关掉它，它就是关掉了。

  • 打开很快，而且回到你上次离开的地方。
  • 给你发任何东西之前都会先问你。
  • 明年和今天用起来一模一样。

最后一点比听上去更重要：你烂熟于心的工具，都是从不改动的那些。

功能

刻意保持小巧。

只做少数几件事，并认真做好。一条纤细的工具栏，没有书签栏，没有角标，也没有弹窗。网页占据几乎整个窗口。

一个安静的侧边栏

标签页和空间集中在一处，基于 Chromium 自带的垂直标签页。想要更大的页面时，可以收起为图标。

Peek

Shift+点击链接，在你正在阅读的页面上方打开一个小页面。按 Esc 关闭，或不重新加载直接转为标签页。

空间

个人、工作、爱好：每个空间有自己的标签页和颜色，重启后依然保留。用 ⌃ 1…9 或在侧边栏上双指滑动切换。空间可以运行在独立的配置文件中，让登录互相分开。

小窗口

完全没有标签页的小窗口，适合聊天里的链接或临时查个东西：⌥ ⌘ N，或链接的菜单。真有用时，再把它移入某个空间。

命令栏

⌘ T 和 ⌘ L 打开同一个面板，用键盘即可搜索打开的标签页、书签、历史记录、命令和搜索内容。

你用的扩展程序

桌面版底层是 Chromium，所以开发者工具和画中画都在。从 Chrome Web Store 安装扩展程序，首次运行时选择密码管理器：1Password、Bitwarden 或 Proton Pass。和 Chrome 本身一样，只有 Manifest V3 扩展程序可以运行。

从 Arc、Chrome、Edge 或 Safari 迁移过来

从 Chrome、Edge、Brave 等 Chromium 浏览器、Firefox、Safari 或书签文件带上你的书签、历史记录、搜索快捷方式、地址和打开的标签页。从 Arc 导入时，空间、固定标签页、常用项和配置文件也会一起带过来。你的扩展程序会从 Chrome Web Store 重新安装，也可以选择保持登录状态。密码仍由你的密码管理器保管。

自动更新

在 Mac 上，它每四小时检查一次新版本，验证更新签名后，安装前先询问你。安全更新无法跳过，因此上游 Chromium 的修复发布后不久就会送到你手上。

查看全部功能，包括标签页组、广告拦截，以及各平台的支持情况。

隐私

默认注重隐私。无需注册任何账户。

我们不会持有任何关于你的可读数据。无需创建账户，也没有保存你历史记录的服务器。

无遥测

没有使用统计、实验或浏览器登录。它以 ungoogled-chromium 为基础，后者移除了 Google 的后台服务。

内置广告和跟踪器拦截

所有网站都会拦截广告和跟踪器请求，EasyList、EasyPrivacy、uBlock 过滤规则和 Peter Lowe 的列表由维护者保持更新。你可以在网站信息面板中允许某个网站的广告。残留的广告空位也会被隐藏，链接在页面加载前会去掉跟踪参数（utm_source、fbclid、gclid 等）。

更严格的默认设置

第三方 Cookie 默认被拦截，站点隔离保持开启。HTTPS 优先已开启：网站通过 HTTPS 加载，若以普通 HTTP 打开，会先给出警告。

你拥有的同步 即将推出

端到端加密，设备到设备，或通过你自己的 iCloud、Google Drive、Dropbox 或 WebDAV。用二维码配对设备。

搜索引擎由你选择

没有默认项。首次运行时选择，搜索建议保持关闭，因此输入时不会发送任何内容。

安全浏览，仅标准模式

与本地的哈希前缀列表比对，没有实时查询。威胁列表需要与 Google 签订协议，我们尚未完成，所以目前还没有数据。

常见问题

值得了解。

Little Browser 是 Arc 的替代品吗？

是。它受 Arc 启发，有侧边栏、空间、固定标签页、标签页组、Peek 和命令栏，并可导入你的 Arc 空间和标签页。它是独立的，与 The Browser Company 没有关联。看看它们的对比。

什么是 Peek？

Shift+点击链接，在你页面上方的卡片中阅读，然后关闭，或不重新加载直接保留为标签页。进一步了解 Peek。

它能在哪些电脑上运行？

测试版面向 Apple 芯片的 Mac。Windows、Linux、iPhone 和 Android 版本暂不提供。

需要账户吗？

不需要。没有账户，没有遥测，也没有统计分析。参见隐私政策。
