功能 / 自动更新

自动、带签名的更新，紧跟 Chromium 安全修复

每四小时检查一次，安装前会先询问，Chromium 的安全修复数日内跟进。

更新落后的浏览器是一种风险，所以 Little Browser 紧跟 Chromium 的稳定版发布：每四周一个新的主版本，安全修复数日内跟进。

更新的过程

  • 浏览器运行期间每四小时检查一次。检查只发送当前版本和你的平台。
  • 一个小提示。安装更新会下载并提示你重启以完成更新。稍后提醒我会推迟一天。跳过此版本则放过这一版。
  • 安装前先验证。每个更新的签名都会用内置在应用中的密钥验证，同时验证其 Apple 签名。
  • 安全更新无法跳过。提示会说明它很重要，并在下一次检查时再次询问。

为更新而重启时，不会询问“退出 Little Browser？”。每个版本的变化见发行说明页面。

其他平台

Windows 和 Linux 推出后，更新会包含在内：Windows 使用我们自己的更新程序，Linux 通过软件包仓库。Android 和 iOS 的更新则交给各自的应用商店。

平台支持

每项功能都计划覆盖所有平台。以下是自动更新目前的情况。

相关内容

广告拦截和跟踪防护所有网站都会拦截广告和跟踪器，第三方 Cookie 默认关闭，你点击的链接也会去掉跟踪参数。 Chrome 扩展程序桌面版底层是 Chromium。可从 Chrome Web Store 安装扩展程序，首次启动时选择一款密码管理器。 从 Arc、Chrome 等浏览器导入带上书签、历史记录、搜索快捷方式、地址和打开的标签页。从 Arc 导入时，空间和固定标签页也会一起带过来。

常见问题

Little Browser 多久更新一次？

每四小时检查一次，并跟随 Chromium 的稳定版发布：每四周一个新的主版本，安全修复数日内跟进。

可以跳过更新吗？

常规更新可以跳过，或者第二天再提醒。安全更新无法跳过。

更新检查会发送什么？

只有当前版本和你的平台。没有其他内容，也没有系统配置信息。
