从 Arc、Chrome、Edge、Firefox 和 Safari 导入

带上书签、历史记录、搜索快捷方式、地址和打开的标签页。从 Arc 导入时，空间和固定标签页也会一起带过来。

导入对话框会在首次运行时打开，之后也可以从命令栏（“从其他浏览器导入”）、应用菜单或设置中打开。它只列出在你的 Mac 上找到的浏览器。

从哪里导入

  • Arc，包括空间、固定标签页和配置文件。
  • Chrome、Edge、Brave、Chromium、Opera 和 Vivaldi，包括它们的配置文件。
  • Firefox，包括它的配置文件。
  • Safari，需要 Little Browser 拥有“完全磁盘访问权限”才能读取其书签。否则请从 Safari 导出，再选择导出的文件。
  • 书签文件（HTML），所有浏览器都可以导出。

常见问题

可以从 Arc 导入吗？

可以。它的空间、固定标签页、打开的标签页、书签、历史记录和配置文件都会带过来，扩展程序则从 Chrome Web Store 重新安装。

导入会带上我的密码吗？

不会。密码和支付卡不会被带过来。密码由密码管理器扩展程序负责，它们都能导入你的密码。

可以从 Safari 导入吗？

可以。要么给 Little Browser “完全磁盘访问权限”，让它读取 Safari 的书签，要么从 Safari 导出数据，再选择导出的文件。
