功能

Little Browser 的功能

一款小巧、注重隐私、拥有类 Arc 侧边栏的浏览器。只做少数几件事，并认真做好，每一项都有自己的页面。

浏览

标签页、窗口和链接的工作方式。

垂直标签页侧边栏

标签页和空间集中在一个安静的侧边栏中，基于 Chromium 自带的垂直标签页。隐藏之后，网页占满整个窗口。

了解更多

空间

个人、工作、爱好：每个空间有自己的标签页和颜色，重启后依然保留。

了解更多

固定标签页和标签页名称

固定标签页会休眠而不是关闭，并记住自己的链接；名称由你决定，旧标签页会自动归档。

了解更多

标签页组

有名称、可折叠的标签页组，三个标签页相关时会提议创建，固定的标签页组也可以。

了解更多

命令栏

⌘T 和 ⌘L 打开同一个面板，用键盘即可搜索标签页、书签、历史记录、命令和搜索内容。

了解更多

Peek

Shift+点击链接，在你正在阅读的页面上方打开一个小页面。按 Esc 关闭，或不重新加载直接转为标签页。

了解更多

小窗口

完全没有标签页的小窗口，适合聊天里的链接或临时查个东西。需要时可将它移入某个空间。

了解更多

默认注重隐私

浏览器无需你开口就替你做好的事。

广告拦截和跟踪防护

原生广告拦截，第三方 Cookie 默认关闭，你点击的链接会去掉跟踪参数。无遥测。

了解更多

Chrome 扩展程序

Chrome Web Store 扩展程序、Manifest V3，以及开发者工具和画中画。首次运行时选择 1Password、Bitwarden 或 Proton Pass。

了解更多

迁入并保持最新

带上你的东西，并让浏览器保持最新。

从 Arc、Chrome 等浏览器导入

书签、历史记录、搜索快捷方式、地址和打开的标签页，从 Arc 导入时还有它的空间和固定标签页。

自动更新

每四小时检查一次新版本，验证签名后，安装前先询问你。

平台
