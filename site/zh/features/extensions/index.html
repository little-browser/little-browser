Chrome 扩展程序和密码管理器

桌面版底层是 Chromium。可从 Chrome Web Store 安装扩展程序，首次启动时选择一款密码管理器。

Little Browser 基于 Chromium，所以大家依赖的东西都在：开发者工具、画中画和 Chrome Web Store。

扩展程序

  • 来自 Chrome Web Store。从商店自己的页面安装，并由商店更新，和 Chrome 一样。
  • 仅支持 Manifest V3。Chrome 本身已在 2026 年移除最后的 Manifest V2 开关，要保留它们，就得每个版本都去修补上游已经删掉的代码。
  • 安静的更新。更新检查只发送找到正确版本所需的信息，没有点名或活跃用户上报，没有安装 ID，也没有安装或卸载事件。
  • 你的广告拦截扩展仍然可用。浏览器有原生拦截器，想用 uBlock Origin Lite（Manifest V3）的人也可以使用。
  • 在无痕窗口中，扩展程序默认关闭，除非你主动开启。

密码管理器，由你选择

Little Browser 没有自带密码管理器。首次运行时会提供 1Password、Bitwarden 或 Proton Pass，都从 Chrome Web Store 安装，并显示 Chromium 常规的权限提示。也可以跳过，之后再添加任何扩展程序。导入时不会带上其他浏览器的密码，这些由你的密码管理器导入。

相关内容

广告拦截和跟踪防护所有网站都会拦截广告和跟踪器，第三方 Cookie 默认关闭，你点击的链接也会去掉跟踪参数。 从 Arc、Chrome 等浏览器导入带上书签、历史记录、搜索快捷方式、地址和打开的标签页。从 Arc 导入时，空间和固定标签页也会一起带过来。 自动更新每四小时检查一次，安装前会先询问，Chromium 的安全修复数日内跟进。

常见问题

可以安装 Chrome 扩展程序吗？

可以，从 Chrome Web Store 安装，和 Chrome 一样。只有 Manifest V3 扩展程序可以运行。

支持 Manifest V2 扩展程序吗？

不支持。Chrome 已在 2026 年移除最后的 Manifest V2 开关。Little Browser 有原生广告拦截器，使用 Manifest V3 的 uBlock Origin Lite 也可以使用。

哪些密码管理器可以使用？

Chrome Web Store 中的任何扩展程序都可以。首次运行时，Little Browser 提供 1Password、Bitwarden 和 Proton Pass。
