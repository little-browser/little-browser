功能 / 空间

空间：为生活的每一部分准备一个浏览器标签页侧边栏

个人、工作、爱好：每个空间有自己的标签页、名称和颜色，重启后依然保留。

空间是为生活中某一部分准备的地方，有自己的标签页、名称，以及为侧边栏着色的颜色。切换空间时，侧边栏会滑到另一组标签页，后面的页面也随之改变。

空间里有什么

  • 固定标签页和今日标签页。固定标签页会一直保留，今日标签页是你正在处理的。标签页组在两者中都可以使用。
  • 名称、表情符号图标和颜色。可以用侧边栏底部的 + 或命令栏新建。
  • 需要时可用独立的配置文件。给空间一个独立的配置文件，让它的登录、Cookie 和历史记录互相分开，工作和个人账户就不会混在一起。空间不在默认配置文件中时，会显示一个小锁标记。
  • 重启后标签页依然保留。每个窗口都会回到各自的空间。没在使用的空间里的标签页，过一阵会休眠以节省内存，点击后再唤醒。

切换

  • ⌃ 1…9，或 ⌃ ⌥ ← / →
  • 侧边栏底部的空间圆点
  • 在侧边栏上双指横向滑动。在页面本身上滑动，仍然是后退和前进。
  • 右键点击标签页，然后选择“移到空间”。

如果你是从 Arc 转过来的

空间的使用方式和你在 Arc 中习惯的一样，Little Browser 会把你的 Arc 空间连同标签页一起导入。参见 Little Browser：Arc 替代品。

相关内容

垂直标签页侧边栏标签页和空间集中在网页旁边的一处。隐藏之后，网页占满窗口，侧边栏只需把指针移过去就会出现。 固定标签页和标签页名称固定的标签页会留着，名称由你决定，归档让今日列表保持简短。 从 Arc、Chrome 等浏览器导入带上书签、历史记录、搜索快捷方式、地址和打开的标签页。从 Arc 导入时，空间和固定标签页也会一起带过来。

常见问题

什么是空间？

一组带有名称、图标和颜色的固定标签页和今日标签页。可以为生活的每一部分各用一个：个人、工作、爱好。

如何切换空间？

按 Ctrl+1…9，使用侧边栏底部的圆点，或在侧边栏上用双指横向滑动。

空间和配置文件是一回事吗？

不是。配置文件是一套登录、Cookie 和历史记录。每个空间都使用一个配置文件，多个空间可以共用一个。每个人一开始只有一个配置文件，所以只有想把登录分开时，才会接触到这个概念。

可以带上我的 Arc 空间吗？

可以。导入会读取 Arc 的空间，包括其中的固定标签页、打开的标签页，以及对应的配置文件。
