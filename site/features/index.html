Features

Features of Little Browser

A small, private browser with an Arc-like sidebar. Only a few things, done carefully, and every one of them has its own page.

Browse

How tabs, windows and links work.

Vertical tab sidebar

Tabs and spaces in one quiet sidebar built on Chromium’s own vertical tabs. Hide it and the page gets the whole window.

Read more

Spaces

Personal, work, a hobby: each space has its own tabs and its own colour, and comes back after a restart.

Read more

Pinned tabs and tab names

Pinned tabs that sleep instead of closing and remember their link, names you choose, and old tabs archived for you.

Read more

Tab groups

Named, collapsible groups, offered when three tabs belong together. Pinned groups too.

Read more

Command bar

⌘T and ⌘L open one palette for your tabs, bookmarks, history, commands and searches, all from the keyboard.

Read more

Peek

Shift+click a link to open a little page over the one you’re reading. Press Esc to let it go, or turn it into a tab without reloading.

Read more

Little window

A small window with no tabs at all, for the link from a chat or a quick look-up. Move it into a space when it matters.

Read more

Private by default

What the browser does for you without being asked.

Ad blocker and tracking protection

A native ad blocker, third-party cookies off, and tracking parameters stripped from the links you follow. No telemetry.

Read more

Chrome extensions

Chrome Web Store extensions, Manifest V3, plus DevTools and Picture-in-Picture. Pick 1Password, Bitwarden or Proton Pass on first run.

Read more

Move in and stay current

Bring your things along, and keep the browser up to date.

Import from Arc, Chrome and others

Bookmarks, history, search shortcuts, addresses and open tabs, and from Arc its spaces and pinned tabs too.

Read more

Automatic updates

Checks for a new version every four hours and asks before installing, after checking its signature.

Read more

Platforms

Little Browser is a beta for Macs with Apple silicon today. The other platforms are built to match it, feature for feature, and use what each system allows: Chromium on desktop and Android, WebKit on iPhone and iPad, as Apple requires.
