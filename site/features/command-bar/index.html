Features / Command bar

Command bar: one palette for tabs, history and searches

One palette in the middle of the window for open tabs, bookmarks, history, commands and searches, all from the keyboard.

The command bar is where you go to do almost anything: open a page, find a tab, run a command, search the web. It floats in the middle of the window and opens in under 50 milliseconds, as part of the browser rather than as a web page.

Two ways in

  • ⌘ T opens it empty, for a new tab.
  • ⌘ L opens it on the current address, selected, to edit it.

One list for everything

Results come in one list, ranked by fuzzy match:

  • Open tabs, across all your spaces: pick one to switch to it.
  • Pinned tabs, bookmarks and history.
  • Archived tabs and groups, found by name. See auto-archive.
  • Commands: Toggle sidebar, New space, Tabs on top, Incognito window, New little window, Copy URL, Allow ads on this site, Import from another browser, and more.
  • An address, or a search with the engine you picked.

Enter takes the top result, the arrow keys move, and Esc closes it and hands focus back to the page.

No default search engine

On first run you choose a search engine, with privacy-respecting ones listed first. Search suggestions are off until you turn them on, because each keystroke would otherwise go to the search provider.

Questions

What is the command bar?

A floating palette that finds open tabs, bookmarks, history, archived tabs and commands, and turns anything else into an address or a search. ⌘T opens it for a new tab and ⌘L for the current address.

Can I switch tabs from the command bar?

Yes. Open tabs from every space are listed, so you can type part of a title and press Enter to switch to it.

Does it send what I type to a search engine?

No. Search suggestions are off by default, so nothing you type goes to a search provider until you press Enter on a search.
