Features / Automatic updates

Automatic, signed updates that follow Chromium security fixes

A check every four hours, a prompt before anything installs, and security fixes from Chromium within days.

A browser that's behind on updates is a risk, so Little Browser follows Chromium's stable releases closely: a new major version every four weeks, and security fixes within days.

How an update goes

  • A check every four hours while the browser runs. The check sends only the current version and your platform.
  • A small prompt. Install Update downloads it and offers to restart into it. Remind Me Later holds it back for a day. Skip This Version passes on it.
  • Checked before it installs. Each update's signature is verified against a key built into the app, along with its Apple signature.
  • Security updates can't be skipped. The prompt says it's important and asks again at the next check.

The restart into an update doesn't ask "Quit Little Browser?". Each release's changes are on the release notes page.

On other platforms

As Windows and Linux arrive, updates will be part of them: Windows with an updater of our own, Linux through a package repository. Android and iOS leave updates to their app stores.

Questions

How often does Little Browser update?

It checks every four hours, and follows Chromium’s stable releases: a new major version every four weeks and security fixes within days.

Can I skip an update?

You can skip a regular update, or be reminded the next day. A security update can’t be skipped.

What does the update check send?

Only the current version and your platform. Nothing else, and no system profile.
