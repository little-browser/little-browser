Chrome-Erweiterungen und Passwortmanager

Auf dem Desktop steckt Chromium darunter. Installiere Erweiterungen aus dem Chrome Web Store und wähle beim ersten Start einen Passwortmanager.

Little Browser basiert auf Chromium, daher kommt mit, worauf man sich verlässt: DevTools, Bild-in-Bild und der Chrome Web Store.

Erweiterungen

  • Aus dem Chrome Web Store. Installiere sie von den Seiten des Stores, und sie werden wie in Chrome von dort aktualisiert.
  • Nur Manifest V3. Chrome selbst hat die letzten Manifest-V2-Schalter 2026 entfernt, und sie am Leben zu halten hieße, bei jedem Release Code zu pflegen, den das Upstream-Projekt gelöscht hat.
  • Leise Updates. Eine Update-Prüfung sendet nur, was nötig ist, um die richtige Version zu finden, keine Rundrufe oder Pings aktiver Nutzer, keine Installations-IDs und keine Installations- oder Deinstallationsereignisse.
  • Deine Werbeblocker-Erweiterung funktioniert weiterhin. Der Browser hat einen nativen Blocker, und uBlock Origin Lite (Manifest V3) funktioniert ebenfalls, wenn du es zusätzlich möchtest.
  • In einem privaten Fenster sind Erweiterungen aus, solange du sie nicht einschaltest.

Ein Passwortmanager deiner Wahl

Little Browser hat keinen eigenen Passwortmanager. Beim ersten Start bietet er 1Password, Bitwarden oder Proton Pass an, jeweils aus dem Chrome Web Store installiert, mit der üblichen Berechtigungsabfrage von Chromium. Überspringe das und füge später eine beliebige Erweiterung hinzu. Passwörter aus anderen Browsern kommen beim Import nie mit; die importiert dein Passwortmanager.

Verwandt

Werbeblocker und Tracking-SchutzWerbung und Tracker werden auf jeder Website blockiert, Drittanbieter-Cookies sind aus, und Tracking-Parameter werden aus den Links entfernt, denen du folgst. Import aus Arc, Chrome und anderenBring deine Lesezeichen, deinen Verlauf, Suchkürzel, Adressen und geöffnete Tabs mit. Von Arc kommen auch deine Spaces und angehefteten Tabs mit. Automatische UpdatesAlle vier Stunden eine Prüfung, eine Rückfrage vor jeder Installation und Sicherheitskorrekturen von Chromium innerhalb weniger Tage.

Fragen

Kann ich Chrome-Erweiterungen installieren?

Ja, aus dem Chrome Web Store, wie in Chrome. Es laufen nur Manifest-V3-Erweiterungen.

Unterstützt er Manifest-V2-Erweiterungen?

Nein. Chrome hat die letzten Manifest-V2-Schalter 2026 entfernt. Little Browser hat einen nativen Werbeblocker, und uBlock Origin Lite, das Manifest V3 nutzt, funktioniert ebenfalls.

Welche Passwortmanager funktionieren?

Jede Erweiterung aus dem Chrome Web Store. Beim ersten Start bietet Little Browser 1Password, Bitwarden und Proton Pass an.
