Пашырэнні Chrome і менеджары пароляў

На камп’ютары пад капотам Chromium. Усталёўвайце пашырэнні з Chrome Web Store і выбірайце менеджар пароляў пры першым запуску.

Little Browser пабудаваны на Chromium, таму тое, на што людзі спадзяюцца, ідзе ў камплекце: DevTools, «Карцінка ў карцінцы» (Picture-in-Picture) і Chrome Web Store.

Пашырэнні

  • З Chrome Web Store. Усталёўвайце з уласных старонак краме, і яны будуць абнаўляцца адтуль, як у Chrome.
  • Толькі Manifest V3. Сам Chrome прыбраў апошнія пераключальнікі Manifest V2 у 2026 годзе, а іх захаванне патрабавала б правіць код, які выдалены ў асноўным праекце, выпуск за выпускам.
  • Ціхія абнаўленні. Праверка абнаўлення адпраўляе толькі тое, што трэба для пошуку патрэбнай версіі, — ніякіх «пераклічак» і сігналаў актыўных карыстальнікаў, ніякіх ідэнтыфікатараў усталёўкі, ніякіх падзей пра ўстаноўку ці выдаленне.
  • Ваша пашырэнне-блакавальнік па-ранейшаму працуе. У браўзеры ёсць убудаваны блакавальнік, і uBlock Origin Lite (Manifest V3) таксама працуе для тых, хто яго хоча.
  • У прыватным акне пашырэнні выключаны, пакуль вы іх не ўключыце.

Менеджар пароляў — на ваш выбар

У Little Browser няма ўласнага менеджара пароляў. Пры першым запуску ён прапануе 1Password, Bitwarden або Proton Pass, кожны ўсталёўваецца з Chrome Web Store са звычайным запытам дазволаў Chromium. Прапусціце гэта і дадайце любое пашырэнне пазней. Паролі з іншых браўзераў ніколі не пераносяцца пры імпарце; іх імпартуе ваш менеджар пароляў.

Пытанні

Ці можна ўсталёўваць пашырэнні Chrome?

Так, з Chrome Web Store, як у Chrome. Працуюць толькі пашырэнні Manifest V3.

Ці падтрымліваюцца пашырэнні Manifest V2?

Не. Chrome прыбраў апошнія пераключальнікі Manifest V2 у 2026 годзе. У Little Browser ёсць убудаваны блакавальнік рэкламы, а таксама працуе uBlock Origin Lite, які падтрымлівае Manifest V3.

Якія менеджары пароляў працуюць?

Любое пашырэнне з Chrome Web Store. Пры першым запуску Little Browser прапануе 1Password, Bitwarden і Proton Pass.
