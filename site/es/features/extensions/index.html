Extensiones de Chrome y gestores de contraseñas

En el escritorio, por debajo es Chromium. Instala extensiones desde la Chrome Web Store y elige un gestor de contraseñas al empezar.

Little Browser está basado en Chromium, así que vienen con él las cosas en las que la gente confía: DevTools, imagen en imagen y la Chrome Web Store.

Extensiones

  • Desde la Chrome Web Store. Instálalas desde las páginas de la propia tienda y se actualizan desde ella, como en Chrome.
  • Solo Manifest V3. El propio Chrome eliminó en 2026 los últimos interruptores de Manifest V2, y mantenerlos vivos supondría parchear código que el proyecto original ha borrado, versión tras versión.
  • Actualizaciones discretas. Una comprobación de actualización envía lo necesario para encontrar la versión correcta, y no hay llamadas de presencia ni avisos de usuario activo, ni identificadores de instalación, ni eventos de instalación o desinstalación.
  • Tu extensión de bloqueo de anuncios sigue funcionando. El navegador tiene un bloqueador nativo, y uBlock Origin Lite (Manifest V3) funciona también para quien lo quiera.
  • En una ventana privada, las extensiones están desactivadas a menos que las actives.

Un gestor de contraseñas, a tu elección

Little Browser no tiene gestor de contraseñas propio. En el primer arranque ofrece 1Password, Bitwarden o Proton Pass, cada uno instalado desde la Chrome Web Store con el aviso de permisos habitual de Chromium. Sáltatelo y añade cualquier extensión más tarde. Las contraseñas de otros navegadores nunca vienen al importar; tu gestor de contraseñas las importa.

Preguntas

¿Puedo instalar extensiones de Chrome?

Sí, desde la Chrome Web Store, como en Chrome. Solo se ejecutan extensiones Manifest V3.

¿Admite extensiones Manifest V2?

No. Chrome eliminó en 2026 los últimos interruptores de Manifest V2. Little Browser tiene un bloqueador de anuncios nativo, y uBlock Origin Lite, que es Manifest V3, también funciona.

¿Qué gestores de contraseñas funcionan?

Cualquier extensión de la Chrome Web Store. En el primer arranque, Little Browser ofrece 1Password, Bitwarden y Proton Pass.
