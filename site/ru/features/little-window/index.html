Малое окно: небольшое окно браузера без вкладок

Небольшое окно без вкладок для ссылки из чата или быстрой справки. Когда оно окажется важным, перенесите его в пространство.

Не каждой странице нужна вкладка. Малое окно — это небольшое окно браузера без боковой панели и без вкладок, чтобы быстрая справка не копилась в куче.

Как открыть

  • ⌥ ⌘ N или Новое малое окно в меню «Файл» открывает командную панель для малого окна. Что бы вы ни выбрали, оно откроется там.
  • Щёлкните ссылку правой кнопкой и выберите Открыть ссылку в малом окне.
  • Ссылки из других приложений, например из почты или мессенджера, открываются в собственном малом окне, а не во вкладке основного окна.

Что в нём есть

Страница и одна строка под заголовком окна с её адресом, кнопками Копировать URL и Открыть в ‹пространстве›. Последняя кнопка переносит страницу в окно с этим пространством как активную вкладку, без перезагрузки. Малых окон можно открыть несколько, а ⌘ W закрывает одно из них.

Всё, что Little Browser блокирует в других местах, он блокирует и здесь.

Вопросы

Что такое малое окно?

Небольшое окно браузера без боковой панели и вкладок для одной страницы. Оно предназначено для ссылок из других приложений и быстрой справки.

Можно ли сохранить страницу из малого окна?

Да. «Открыть в пространстве» переносит страницу в основное окно как вкладку, без перезагрузки.

Открываются ли ссылки из других приложений в малом окне?

Да. Ссылка из почты или мессенджера открывается в собственном малом окне, а не во вкладке основного.
