Λειτουργίες / Αυτόματες ενημερώσεις

Αυτόματες, υπογεγραμμένες ενημερώσεις που ακολουθούν τις διορθώσεις ασφαλείας του Chromium

Έλεγχος κάθε τέσσερις ώρες, ερώτηση πριν εγκατασταθεί οτιδήποτε και διορθώσεις ασφαλείας από το Chromium μέσα σε λίγες ημέρες.

Ένα πρόγραμμα περιήγησης που καθυστερεί στις ενημερώσεις είναι κίνδυνος, γι' αυτό το Little Browser ακολουθεί στενά τις σταθερές εκδόσεις του Chromium: μια νέα κύρια έκδοση κάθε τέσσερις εβδομάδες και διορθώσεις ασφαλείας μέσα σε λίγες ημέρες.

Πώς γίνεται μια ενημέρωση

  • Έλεγχος κάθε τέσσερις ώρες όσο τρέχει το πρόγραμμα περιήγησης. Ο έλεγχος στέλνει μόνο την τρέχουσα έκδοση και την πλατφόρμα σας.
  • Ένα μικρό μήνυμα. Το Install Update την κατεβάζει και προτείνει επανεκκίνηση για να περάσετε σε αυτήν. Το Remind Me Later την αναβάλλει για μία ημέρα. Το Skip This Version την προσπερνά.
  • Έλεγχος πριν από την εγκατάσταση. Η υπογραφή κάθε ενημέρωσης επαληθεύεται με ένα κλειδί ενσωματωμένο στην εφαρμογή, μαζί με την υπογραφή της Apple.
  • Οι ενημερώσεις ασφαλείας δεν μπορούν να παραλειφθούν. Το μήνυμα λέει ότι είναι σημαντική και ρωτά ξανά στον επόμενο έλεγχο.

Η επανεκκίνηση για μια ενημέρωση δεν ρωτά «Quit Little Browser?». Οι αλλαγές κάθε έκδοσης βρίσκονται στη σελίδα με τις σημειώσεις έκδοσης.

Σε άλλες πλατφόρμες

Όταν έρθουν τα Windows και το Linux, οι ενημερώσεις θα αποτελούν μέρος τους: στα Windows με δικό μας πρόγραμμα ενημέρωσης, στο Linux μέσω αποθετηρίου πακέτων. Το Android και το iOS αφήνουν τις ενημερώσεις στα καταστήματα εφαρμογών τους.

Ερωτήσεις

Ελέγχει κάθε τέσσερις ώρες και ακολουθεί τις σταθερές εκδόσεις του Chromium: μια νέα κύρια έκδοση κάθε τέσσερις εβδομάδες και διορθώσεις ασφαλείας μέσα σε λίγες ημέρες.

Μπορώ να παραλείψω μια ενημέρωση;

Μπορείτε να παραλείψετε μια τακτική ενημέρωση ή να σας υπενθυμιστεί την επόμενη ημέρα. Μια ενημέρωση ασφαλείας δεν μπορεί να παραλειφθεί.

Τι στέλνει ο έλεγχος ενημερώσεων;

Μόνο την τρέχουσα έκδοση και την πλατφόρμα σας. Τίποτα άλλο, και κανένα προφίλ συστήματος.
