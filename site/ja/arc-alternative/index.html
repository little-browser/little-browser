Arc からお越しですか？

Mac 向け Arc の代替ブラウザ

Arc は提供終了となります。Little Browser は、多くの人に愛された Arc の魅力であるサイドバー、スペース、Peek を備えた、小さくてプライバシー重視のオープンソースブラウザです。

The Browser Company が開発したサイドバー型ブラウザ Arc は、サービスを終了します。新規アカウントの受け付けは 2026年10月22日に終了し、2026年12月22日には macOS 版と Windows 版の Arc が動作しなくなり、アカウントも無効になります。開発チームは新しいブラウザ Dia に注力しています。詳細は Arc 自身の発表をご覧ください。

Little Browser は、Arc と同じ考えから始まりました。タブは横に置き、生活の場面ごとにスペースを用意し、ウィンドウはページに使います。Arc に着想を得た独立したオープンソースのブラウザなので、他社の方針で終了してしまうことはありません。

タブ、スペース、ブックマークの移行

Little Browser は初回起動時にインポートを案内し、その後もコマンドバー（「他のブラウザからインポート」）から実行できます。Arc からは、スペース（とその元になっているプロファイル）、開いているタブ、ピン留めタブとお気に入り、ブックマーク、履歴、検索ショートカット、拡張機能を取り込みます。取り込む内容は選べます。ログイン状態の引き継ぎは任意で、パスワードはパスワードマネージャーに残ります。インポート中も Arc は開いたままで構いません。

Arc 自身の設定（Arc › 設定 › 詳細 › データを書き出す）でも、タブをリンクの一覧として保存できます。12月22日までに済ませておくと安心です。

違うところ

  • アカウント不要、テレメトリなし。履歴、タブ、パスワードはお使いのデバイスの中にとどまります。プライバシーポリシーをご覧ください。
  • オープンソース。コードは MPL-2.0 で GitHub に公開されています。
  • 広告とトラッカーのブロックを内蔵し、標準の Chromium より厳しい初期設定になっています。
  • AI 機能はありません。Boost や Easel もありません。
  • まだ初期段階です。ベータ版で、Apple シリコン搭載の Mac のみ対応しています。Windows 版、Linux 版、モバイル版はまだなく、デバイス間の同期は設計済みですが未実装です。

よくある質問

Arc は提供終了になりますか？

はい。開発元の The Browser Company は Arc を終了します。新規アカウントの受け付けは 2026年10月22日に停止し、2026年12月22日に macOS 版と Windows 版の Arc が動作しなくなります。スケジュールは Arc 自身の発表をご覧ください。

Mac 向けのおすすめの Arc の代替ブラウザは？

Arc のどこが好きだったかによります。サイドバー、スペース、Peek が好きで、アカウントや AI は要らないという方に向けて作られているのが Little Browser です。Apple シリコン搭載 Mac 向けのベータ版で、オープンソースであり、データはお使いのデバイスに残ります。

Arc のスペースやタブをインポートできますか？

はい。Little Browser のインポートでは、Arc のスペース、プロファイル、開いているタブ、ピン留めタブとお気に入り、さらにブックマーク、履歴、検索ショートカット、拡張機能を読み込めます。Arc がインストールされているうちに、つまり 2026年12月22日より前にインポートしてください。

Little Browser に Peek はありますか？

はい。Arc と同じように、リンクを Shift+クリックすると、読んでいるページの上にカードとして開きます。Peek について詳しく。

Little Browser にアカウントは必要ですか？

いいえ。アカウントもサインインもテレメトリもありません。デバイス間の同期は設計済みですが、まだ実装されていません。

Little Browser にないものは？

Arc の Boost、Easel、AI 機能はありません。また、現時点では Apple シリコン搭載の Mac でのみ動作します。Windows 版、Linux 版、iPhone 版、Android 版はまだ提供されていません。

Little Browser をダウンロード Little Browser とは

Little Browser は独立したプロジェクトであり、The Browser Company および Dia とは関係ありません。Arc と Dia は、それぞれの開発元の名称および商標です。
