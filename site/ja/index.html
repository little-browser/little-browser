静かなウェブとは

Mara Lindqvist · 11月18日

ほとんどのページは何かを求めてきます。クリック、登録、あなたの夜の時間をもう少し。静かなウェブは何も求めません。いきなりレシピから始まるレシピ、時刻だけを示す時刻表のようなものです。

新しいものではありません。スクロールさせ続けるための仕組みを取り除いたあとに残るもので、スローソフトウェア運動の考え方でもあります。追いかけてくるのではなく、待っていてくれる道具です。

戻ってみると、いちばんよくわかります。読み込まれ、言いたいことを言って、帰らせてくれるサイトは、今ではほとんど古風に感じられ、不思議と安らぎます。

リンクを Shift+クリックすると、ページを離れずにのぞき見できます。

スローソフトウェア

あなたを待ってくれるソフトウェア

スローソフトウェアは、動作が遅いという意味ではありません。ひとつのことをこなし、使っている間は邪魔をせず、戻ってくる理由を作り出さないアプリのことです。

連続記録も、バッジも、赤い点もありません。閉じたら、それで終わりです。

  • すばやく開き、前回の続きから始まります。
  • 何かを送ってくる前に、確認します。
  • 来年も、今日と同じように動きます。

最後のひとつは、思う以上に大切です。体で覚えている道具とは、場所が変わらなかった道具のことだからです。

機能

あえて小さく。

機能は少数に絞って、丁寧に作っています。細いツールバー、ブックマークバーなし、バッジやポップアップもなし。ウィンドウのほとんどをページに使えます。

ひとつの静かなサイドバー

タブとスペースはひとつの場所にまとまっていて、Chromium 標準の縦型タブで作られています。ページをもっと広く使いたいときは、アイコンだけに縮小できます。

Peek

リンクを Shift+クリックすると、読んでいるページの上に小さなページが開きます。Esc で閉じるか、再読み込みなしでタブにできます。

スペース

プライベート、仕事、趣味など。スペースごとに専用のタブとカラーを持ち、再起動後も元に戻ります。⌃ 1…9 か、サイドバー上の 2 本指スワイプで切り替えます。スペースごとに別のプロファイルで動かして、ログイン情報を分けることもできます。

リトルウィンドウ

タブのまったくない小さなウィンドウで、チャットで届いたリンクやちょっとした調べものに便利です。⌥ ⌘ N か、リンクのメニューから開きます。大事なページだとわかったら、スペースに移せます。

コマンドバー

⌘ T と ⌘ L で、開いているタブ、ブックマーク、履歴、コマンド、検索をひとつのパレットからキーボードだけで操作できます。

使っている拡張機能がそのまま

デスクトップ版の中身は Chromium なので、DevTools やピクチャ イン ピクチャもそのまま使えます。拡張機能は Chrome Web Store からインストールでき、パスワードマネージャーは初回起動時に 1Password、Bitwarden、Proton Pass から選べます。Chrome 自体と同じく、動作するのは Manifest V3 の拡張機能のみです。

Arc、Chrome、Edge、Safari から移行

Chrome、Edge、Brave などの Chromium 系ブラウザ、Firefox、Safari、またはブックマークファイルから、ブックマーク、履歴、検索ショートカット、住所、開いているタブを取り込めます。Arc からは、スペース、ピン留めタブ、お気に入り、プロファイルも引き継げます。拡張機能は Chrome Web Store から再インストールされ、ログイン状態を維持するかどうかも選べます。パスワードはパスワードマネージャーに残ります。

自動で更新

Mac では 4 時間ごとに新しいバージョンを確認し、アップデートの署名を検証したうえで、インストール前に確認を求めます。セキュリティアップデートはスキップできないので、上流の Chromium の修正は、公開後すぐに届きます。

すべての機能を見る：タブグループ、広告ブロック、各プラットフォームの対応状況も載っています。

プライバシー

初期設定からプライバシー重視。登録は不要です。

あなたについて読み取れるデータを、私たちが保持することはありません。作成するアカウントも、履歴を保管するサーバーもありません。

テレメトリなし

利用統計もフィールドトライアルもブラウザへのサインインもありません。Google のバックグラウンドサービスを取り除いた ungoogled-chromium が出発点です。

広告とトラッカーのブロックを内蔵

すべてのサイトで広告とトラッカーへのリクエストをブロックします。EasyList、EasyPrivacy、uBlock フィルタ、Peter Lowe のリストは、各メンテナーから常に最新の状態に保たれます。サイトの広告は、その情報パネルから許可できます。広告の名残の空き枠も非表示になり、リンクからは、ページの読み込み前にトラッキング用パラメータ（utm_source、fbclid、gclid など）が取り除かれます。

より厳しい初期設定

サードパーティ Cookie は初期設定でブロックされ、サイト分離も有効のままです。HTTPS ファーストがオンで、サイトは HTTPS で読み込まれ、通常の HTTP で開く場合は事前に警告が出ます。

自分で管理する同期 近日公開

エンドツーエンドで暗号化され、デバイス間で直接、またはご自身の iCloud、Google Drive、Dropbox、WebDAV を通じて同期します。デバイスのペアリングは QR コードで行います。

検索エンジンは自分で選ぶ

初期設定の検索エンジンはありません。初回起動時に選び、検索候補はオフのままなので、入力中に何かが送られることはありません。

セーフブラウジングは標準のみ

ハッシュプレフィックスのローカルリストと照合するだけで、リアルタイムの問い合わせは行いません。脅威リストの利用には Google との契約が必要ですが、その手続きがまだ終わっていないため、現時点ではデータがありません。

よくある質問

知っておきたいこと。

Little Browser は Arc の代替になりますか？

はい。Arc に着想を得ており、サイドバー、スペース、ピン留めタブ、タブグループ、Peek、コマンドバーを備えています。Arc のスペースとタブもインポートできます。独立したプロジェクトで、The Browser Company とは関係ありません。違いを見る。

Peek とは何ですか？

リンクを Shift+クリックすると、今のページの上のカードでリンク先を読め、閉じることも、再読み込みなしでタブとして残すこともできます。Peek について詳しく。

どのコンピューターで動きますか？

ベータ版は Apple シリコン搭載の Mac 向けです。Windows 版、Linux 版、iPhone 版、Android 版はまだ提供されていません。

アカウントは必要ですか？

いいえ。アカウントもテレメトリも解析ツールもありません。プライバシーポリシーをご覧ください。
