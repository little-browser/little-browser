機能 / Chrome 拡張機能

Chrome 拡張機能とパスワードマネージャー

デスクトップ版の中身は Chromium です。拡張機能は Chrome Web Store からインストールでき、パスワードマネージャーは初回起動時に選べます。

Little Browser は Chromium をベースにしているので、頼りにされている機能がそのまま使えます。DevTools、ピクチャ イン ピクチャ、Chrome Web Store などです。

拡張機能

  • Chrome Web Store から。Chrome と同じように、ストアのページからインストールし、ストア経由で更新されます。
  • Manifest V3 のみ。Chrome 自体が 2026 年に最後の Manifest V2 用スイッチを削除しており、それを残すには、上流が削除したコードに毎回パッチを当て続けることになります。
  • 静かなアップデート。更新の確認では、適切なバージョンを見つけるために必要な情報だけを送ります。利用者数の点呼や稼働状況の通知、インストール ID、インストールやアンインストールのイベントは送りません。
  • 広告ブロック拡張機能も引き続き使えます。ブラウザにはネイティブのブロック機能がありますが、uBlock Origin Lite（Manifest V3）を使いたい方はそちらも使えます。
  • プライベートウィンドウでは、オンにしない限り拡張機能は無効です。

パスワードマネージャーは好きなものを

Little Browser 独自のパスワードマネージャーはありません。初回起動時に 1Password、Bitwarden、Proton Pass を案内し、いずれも Chromium 標準の権限確認を経て Chrome Web Store からインストールします。スキップして、あとから好きな拡張機能を追加することもできます。他のブラウザのパスワードはインポートでは引き継がれません。パスワードマネージャーの側で取り込んでください。

関連

広告ブロックとトラッキング防止広告とトラッカーはすべてのサイトでブロックされ、サードパーティ Cookie はオフ、開いたリンクからはトラッキング用パラメータが取り除かれます。 Arc、Chrome などからインポートブックマーク、履歴、検索ショートカット、住所、開いているタブを取り込めます。Arc からは、スペースとピン留めタブも引き継げます。 自動アップデート4 時間ごとに確認し、インストール前に確認を求め、Chromium のセキュリティ修正も数日以内に反映します。

よくある質問

Chrome 拡張機能はインストールできますか？

はい。Chrome と同じように Chrome Web Store からインストールできます。動作するのは Manifest V3 の拡張機能のみです。

Manifest V2 の拡張機能には対応していますか？

いいえ。Chrome は 2026 年に最後の Manifest V2 用スイッチを削除しました。Little Browser にはネイティブの広告ブロック機能があり、Manifest V3 の uBlock Origin Lite も使えます。

使えるパスワードマネージャーは？

Chrome Web Store の拡張機能であれば何でも使えます。初回起動時には、1Password、Bitwarden、Proton Pass を案内します。
