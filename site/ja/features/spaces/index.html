スペース：生活の場面ごとのブラウザタブサイドバー

プライベート、仕事、趣味など。スペースごとに専用のタブ、名前、カラーを持ち、再起動後も元に戻ります。

スペースは、生活の中のひとつの場面のための場所で、専用のタブ、名前、サイドバーを淡く染めるカラーを持ちます。スペースを切り替えると、サイドバーが別のタブのまとまりにスライドし、その背後のページも一緒に切り替わります。

スペースの中身

  • ピン留めタブと今日のタブ。ピン留めタブはそのまま残り、今日のタブは今作業中のものです。タブグループはどちらにも使えます。
  • 名前、絵文字のアイコン、カラー。新しいスペースは、サイドバー下部の + かコマンドバーから作れます。
  • 必要ならプロファイルも。スペースに専用のプロファイルを割り当てると、ログイン情報、Cookie、履歴を分けられ、仕事用とプライベート用のアカウントが混ざりません。スペースが既定のプロファイルでないときは、小さな鍵のバッジが表示されます。
  • 再起動してもタブは残ります。どのウィンドウも、それぞれのスペースで元に戻ります。使っていないスペースのタブは、しばらくするとメモリ節約のためスリープし、クリックすると復帰します。

切り替え方

  • ⌃ 1…9、または ⌃ ⌥ ← / →
  • サイドバー下部のスペースのドット
  • サイドバー上での 2 本指の横スワイプ。ページ上でのスワイプは、これまでどおり戻る・進むになります。
  • タブを右クリックして、「スペースへ移動」を選びます。

Arc からお越しの方へ

スペースは Arc で慣れた方の期待どおりに動き、Little Browser は Arc のスペースをタブごとインポートします。Arc の代替としての Little Browserをご覧ください。

関連

縦型タブのサイドバータブとスペースはページの横にまとまっています。隠せばページがウィンドウいっぱいに広がり、サイドバーはポインタを寄せるだけで現れます。 ピン留めタブとタブ名残り続けるピン留めタブ、自分で付ける名前、今日の一覧を短く保つアーカイブ。 Arc、Chrome などからインポートブックマーク、履歴、検索ショートカット、住所、開いているタブを取り込めます。Arc からは、スペースとピン留めタブも引き継げます。

よくある質問

スペースとは何ですか？

ピン留めタブと今日のタブのまとまりに、名前、アイコン、カラーを付けたものです。プライベート、仕事、趣味など、生活の場面ごとに使い分けられます。

スペースを切り替えるには？

Ctrl+1…9 を押すか、サイドバー下部のドットを使うか、サイドバー上で 2 本指で横にスワイプします。

スペースとプロファイルは同じですか？

いいえ。プロファイルは、ログイン情報、Cookie、履歴をひとまとめにしたものです。どのスペースもいずれかのプロファイルを使い、複数のスペースで共有することもできます。最初はプロファイルがひとつだけなので、ログイン情報を分けたいときにだけ、この考え方に出会います。

Arc のスペースを持ち込めますか？

はい。インポートでは、Arc のスペースを、ピン留めタブ、開いているタブ、元になっているプロファイルとともに読み込みます。
