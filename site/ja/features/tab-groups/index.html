機能 / タブグループ

サイドバーで自動提案されるタブグループ

名前を付けて折りたためるタブのまとまりを、今日のタブにもピン留めタブにも作れます。3 つのタブが関連しているときには提案します。

タブグループは、名前を付けて折りたためるタブのまとまりで、サイドバーの中のフォルダのようなものです。Chromium 標準のタブグループを使っているので、拡張機能やセッションの復元などもそのまま働きます。

グループの作り方

  • 手動で。タブを選んで ⌥ ⌘ G を押すか、右クリックして「新しいグループに追加」を選ぶか、タブを別のタブの真ん中にドラッグします。
  • ワンクリックの提案。今日のタブのうち 3 つが同じプロジェクトまたはサイトのものだと、そのひとつにポインタを重ねると控えめなグループボタンが現れ、コマンドバーにも「…の 3 つのタブをグループ化」が表示されます。
  • 続けて開いたとき。初期設定でオンです。同じプロジェクトまたはサイトのタブを続けて 3 つ目まで開くと、その場で 3 つをグループにまとめます。
  • サイトごとに自動でグループ化。初期設定ではオフです。オンにすると、別々のタイミングで開いた同じサイトのタブもまとめます。

グループはその場で作られ、サイドバーのほかの部分は動きません。グループから取り出したタブが、自動で再びグループ化されることはありません。

同じサイトだけでなく、同じプロジェクトで

GitHub、GitLab（セルフホスト版を含む）、Bitbucket、Jira、Confluence、Google ドキュメント、Notion、Figma では、ドメインではなくプロジェクト単位でタブを照合するので、同じホストにある 2 つのリポジトリが 1 つのグループになることはありません。それ以外ではサイト単位です。独自のホストは、タブの右クリックメニューから追加できます。

グループの使い方

  • ヘッダーをクリックすると折りたたまれ、ダブルクリックで名前を変更できます。メニューには「グループ解除」と「グループを削除」があります。
  • 折りたたんだグループのタブは、早めにスリープします。
  • 使われていないグループは 1 つのまとまりとしてアーカイブされ、名前を指定すればまるごと復元できます。

ピン留めグループ

グループはピン留めタブの中に置くこともできます。その中のタブはピン留めされたままで、閉じるとスリープし、アーカイブされることもありません。グループをまるごとピン留めするには、「+ 新しいタブ」をまたいでドラッグします。

よくある質問

タブをグループ化するには？

タブを選んで ⌥⌘G を押すか、タブを右クリックして「新しいグループに追加」を選ぶか、タブをほかのタブの上にドラッグします。3 つのタブが同じプロジェクトまたはサイトのものだと、Little Browser がグループ化を提案することもあります。

グループをピン留めできますか？

はい。ピン留めしたグループはピン留めタブの中に置かれ、その中のタブは閉じる代わりにスリープし、アーカイブされることもありません。グループを「新しいタブ」をまたいでドラッグすると、まるごとピン留めしたり解除したりできます。

Little Browser はタブを自動でグループ化しますか？

初期設定でオンになっている、限られた場合だけです。同じプロジェクトまたはサイトの新しいタブを続けて 3 つ目まで開くと、その 3 つをグループにまとめます。一致するすべてのタブをグループ化する設定は、初期設定ではオフです。
