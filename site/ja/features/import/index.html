Arc、Chrome、Edge、Firefox、Safari からインポート

ブックマーク、履歴、検索ショートカット、住所、開いているタブを取り込めます。Arc からは、スペースとピン留めタブも引き継げます。

インポートのダイアログは初回起動時に開き、その後はコマンドバー（「他のブラウザからインポート」）、アプリメニュー、設定から開けます。一覧には、お使いの Mac で見つかったブラウザだけが表示されます。

インポート元

  • Arc：スペース、ピン留めタブ、プロファイルを含みます。
  • Chrome、Edge、Brave、Chromium、Opera、Vivaldi：それぞれのプロファイルを含みます。
  • Firefox：プロファイルを含みます。
  • Safari：Little Browser にフルディスクアクセスを許可すると、ブックマークを読み込めます。許可しない場合は、Safari から書き出して、その書き出しファイルを選びます。
  • ブックマークファイル（HTML）：どのブラウザでも書き出せます。

拡張機能は、確認後に Chrome Web Store から再インストールされます。ストア以外から入れたものは件数でお知らせします。パスワードと支払いカードは引き継がれません。パスワードはパスワードマネージャーで取り込んでください。読み込めない部分があった場合は、ダイアログでどの部分かをお知らせし、残りをインポートします。

Arc からお越しですか？Arc の代替としての Little Browserをご覧ください。

よくある質問

Arc からインポートできますか？

はい。スペース、ピン留めタブ、開いているタブ、ブックマーク、履歴、プロファイルを引き継げ、拡張機能は Chrome Web Store から再インストールされます。

インポートでパスワードも引き継がれますか？

いいえ。パスワードと支払いカードは引き継がれません。パスワードはパスワードマネージャーの拡張機能で扱い、どれも既存のパスワードを取り込めます。

Safari からインポートできますか？

はい。Little Browser にフルディスクアクセスを許可して Safari のブックマークを読み込むか、Safari からデータを書き出して、その書き出しファイルを選びます。
