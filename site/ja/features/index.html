機能

Little Browser の機能

Arc のようなサイドバーを備えた、小さくてプライバシー重視のブラウザです。機能は少数に絞って丁寧に作り、それぞれに専用のページがあります。

ブラウズ

タブ、ウィンドウ、リンクの扱い方。

縦型タブのサイドバー

タブとスペースを、Chromium 標準の縦型タブによる静かなサイドバーにまとめました。隠せば、ウィンドウ全体がページになります。

詳しく見る

スペース

プライベート、仕事、趣味など。スペースごとに専用のタブとカラーを持ち、再起動後も元に戻ります。

詳しく見る

ピン留めタブとタブ名

閉じる代わりにスリープし、リンクを覚えているピン留めタブ、自分で付ける名前、そして古いタブの自動アーカイブ。

詳しく見る

タブグループ

名前を付けて折りたためるグループ。3 つのタブが関連しているときに提案します。ピン留めグループも作れます。

詳しく見る

コマンドバー

⌘T と ⌘L で、タブ、ブックマーク、履歴、コマンド、検索をひとつのパレットからキーボードだけで操作できます。

詳しく見る

Peek

リンクを Shift+クリックすると、読んでいるページの上に小さなページが開きます。Esc で閉じるか、再読み込みなしでタブにできます。

詳しく見る

リトルウィンドウ

タブのまったくない小さなウィンドウで、チャットで届いたリンクや、ちょっとした調べものに便利です。大事なページなら、スペースに移せます。

詳しく見る

初期設定からプライバシー重視

頼まなくてもブラウザがやってくれること。

広告ブロックとトラッキング防止

ネイティブの広告ブロック、サードパーティ Cookie のオフ、開いたリンクからのトラッキング用パラメータの除去。テレメトリはありません。

詳しく見る

Chrome 拡張機能

Chrome Web Store の拡張機能（Manifest V3）に加え、DevTools とピクチャ イン ピクチャも使えます。初回起動時に 1Password、Bitwarden、Proton Pass から選べます。

詳しく見る

移行して、常に最新に

データを持ち込み、ブラウザを最新の状態に保てます。

Arc、Chrome などからインポート

ブックマーク、履歴、検索ショートカット、住所、開いているタブに加え、Arc からはスペースとピン留めタブも引き継げます。

詳しく見る

自動アップデート

4 時間ごとに新しいバージョンを確認し、署名を検証したうえで、インストール前に確認を求めます。

詳しく見る

対応プラットフォーム

Little Browser は現在、Apple シリコン搭載 Mac 向けのベータ版です。他のプラットフォームも、機能を揃えて、各システムで可能な方法で作っています。デスクトップと Android では Chromium、iPhone と iPad では Apple の要件により WebKit を使います。
