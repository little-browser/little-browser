広告ブロックとトラッキング防止を内蔵

広告とトラッカーはすべてのサイトでブロックされ、サードパーティ Cookie はオフ、開いたリンクからはトラッキング用パラメータが取り除かれます。

Little Browser のプライバシー設定は最初からオンで、登録するものもありません。このページでは、広告とトラッカーに対するブラウザの動作を説明します。データの扱いについてはプライバシーポリシーをご覧ください。

最初から入っている広告ブロック

  • すべてのサイトで有効。Chromium 標準のサブリソースフィルタを使うため、リストに一致するリクエストはそもそも送信されません。
  • おなじみのリスト。EasyList、EasyPrivacy、uBlock フィルタ、Peter Lowe のリストを、4 日ごとに各メンテナーから HTTPS で直接ダウンロードします。
  • 空の枠を残しません。要素の非表示により、空のフレームや「広告」のラベルなど、広告の名残も取り除きます。
  • リストからのスクリプトは実行しません。すべてのページでスクリプトを実行するルールは適用されないため、リストが閲覧中のページでコードを実行することはできません。
  • サイトごとに許可。サイトが正しく表示されないときや、サイトを応援したいときは、サイト情報パネルの広告スイッチか、コマンドバーの「このサイトで広告を許可」を使います。そのサイトではブロックも非表示もオフになります。

ブロックした内容の記録は残しません。

トラッキング防止

  • サードパーティ Cookie をブロックし、Chromium のストレージ分割も有効です。
  • トラッキング用パラメータを除去。リンクから utm_*、fbclid、gclid、mc_eid など追跡だけが目的のパラメータが取り除かれるため、アドレスバーにも履歴にもすっきりしたアドレスが残ります。
  • HTTPS を優先。ページは HTTPS で読み込まれ、通常の HTTP で開くサイトでは事前に警告が出ます。
  • テレメトリなし。利用統計も Google のフィールドトライアルもなく、クラッシュレポートは同意した場合のみ送信されます。
  • 検索候補はオフで、オンにするまで使われません。

拡張機能のほうがよければ、uBlock Origin Lite も引き続き使えます。

よくある質問

Little Browser は広告をブロックしますか？

はい。EasyList、EasyPrivacy、uBlock フィルタ、Peter Lowe のリストを使って、すべてのサイトでブロックします。特定のサイトだけ広告を許可することも、サイト情報パネルやコマンドバーから行えます。

サードパーティ Cookie はブロックされますか？

はい、初期設定でブロックされ、Chromium のストレージ分割も有効です。

トラッキング用パラメータとは何ですか？

utm_source や fbclid のように、リンクに付く余分な文字列で、どこから来たかをサイトに伝えるものです。Little Browser は追跡だけが目的のものを取り除くので、表示されるアドレスも残る履歴もすっきりします。

Little Browser は利用データを収集しますか？

いいえ。テレメトリはありません。クラッシュレポートも、同意しない限りオフです。
