Barra de comandos: uma só paleta para abas, histórico e pesquisas

Uma paleta no meio da janela para abas abertas, favoritos, histórico, comandos e pesquisas, tudo pelo teclado.

A barra de comandos é onde você faz quase tudo: abrir uma página, achar uma aba, executar um comando, pesquisar na web. Ela flutua no meio da janela e abre em menos de 50 milissegundos, como parte do navegador e não como uma página da web.

Duas formas de abrir

  • ⌘ T abre vazia, para uma nova aba.
  • ⌘ L abre com o endereço atual selecionado, para editá-lo.

Uma lista para tudo

Os resultados vêm em uma só lista, ordenados por correspondência aproximada:

  • Abas abertas, em todos os seus espaços: escolha uma para ir até ela.
  • Abas fixadas, favoritos e histórico.
  • Abas e grupos arquivados, encontrados pelo nome. Veja o arquivamento automático.
  • Comandos: Mostrar/ocultar barra lateral, Novo espaço, Abas no topo, Janela anônima, Nova janela pequena, Copiar URL, Permitir anúncios neste site, Importar de outro navegador e mais.
  • Um endereço ou uma pesquisa com o buscador que você escolheu.

Enter escolhe o primeiro resultado, as setas se movem e Esc fecha a barra e devolve o foco à página.

Sem buscador padrão

Na primeira execução você escolhe um buscador, com os que respeitam a privacidade listados primeiro. As sugestões de pesquisa ficam desativadas até você ativá-las, porque cada tecla digitada iria para o provedor de busca.

Perguntas

O que é a barra de comandos?

Uma paleta flutuante que encontra abas abertas, favoritos, histórico, abas arquivadas e comandos, e transforma qualquer outra coisa em um endereço ou uma pesquisa. ⌘T abre para uma nova aba e ⌘L para o endereço atual.

Posso trocar de aba pela barra de comandos?

Sim. As abas abertas de todos os espaços aparecem na lista, então você pode digitar parte de um título e apertar Enter para ir até ela.

Ela envia o que eu digito a um buscador?

Não. As sugestões de pesquisa ficam desativadas por padrão, então nada do que você digita vai para um provedor de busca até você apertar Enter em uma pesquisa.
