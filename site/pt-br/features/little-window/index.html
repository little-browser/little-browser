Janela pequena: uma janela de navegador sem abas

Uma janela pequena, sem abas, para o link vindo de um chat ou uma consulta rápida. Mova-a para um espaço quando ela se mostrar importante.

Nem toda página merece uma aba. Uma janela pequena é uma janela de navegador sem barra lateral e sem abas, então uma consulta rápida nunca entra na pilha.

Como abrir

  • ⌥ ⌘ N, ou Nova janela pequena no menu Arquivo, abre a barra de comandos para uma janela pequena. O que você escolher abre ali.
  • Clique com o botão direito em um link e escolha Abrir link em janela pequena.
  • Links de outros apps, como um link em um app de e-mail ou de chat, abrem em uma janela pequena própria, em vez de uma aba na janela principal.

O que ela tem

A página e uma linha sob a barra de título com o endereço, Copiar URL e Abrir em ‹espaço›. Esse último botão move a página para a janela que mostra aquele espaço, como aba ativa, sem recarregá-la. Várias janelas pequenas podem ficar abertas ao mesmo tempo, e ⌘ W fecha uma.

Tudo o que o Little Browser bloqueia em outros lugares, ele bloqueia aqui também.

Perguntas

O que é uma janela pequena?

Uma janela de navegador sem barra lateral nem abas, para uma única página. Serve para links de outros apps e consultas rápidas.

Posso guardar uma página de uma janela pequena?

Sim. Abrir no espaço move a página para a janela principal como aba, sem recarregá-la.

Links de outros apps abrem em uma janela pequena?

Sim. Um link de um app de e-mail ou de chat abre em uma janela pequena própria, não em uma aba da janela principal.
