A made-up `~/Library/Application Support` for the import demos (chromium/lb/README.md): Chrome with
one profile, Arc with two profiles and two spaces, and Edge with two profiles (`Profile 10`
"Studio" and `Profile 11` "Personal", no `Default`, an encrypted copy beside Studio's plain
bookmarks file, and made-up store extensions in each profile's `Secure Preferences`: nine and six,
mostly the same in both, one of Studio's turned off, so the import dialog lists them under each profile and its list is long
enough to scroll). No real browser data. The demos build Chrome's
`History` and `Web Data` from the `.sql` files, and its session and cookie files in code, in a
temporary copy; Edge's session files too, each with an encrypted copy saved just after it.
