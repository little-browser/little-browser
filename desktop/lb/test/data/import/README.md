A made-up `~/Library/Application Support` for the import demos (desktop/lb/README.md): Chrome with
one profile, Arc with two profiles and two spaces, and Dia with one profile laid out as Dia keeps
it (`Profile 10` and no `Default`, an encrypted copy beside the plain bookmarks file). No real
browser data. The demos build Chrome's `History` and `Web Data` from the `.sql` files, and its
session and cookie files in code, in a temporary copy; Dia's session files too, each with an
encrypted copy saved just after it.
