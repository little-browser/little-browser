# Path regexes (Python re, matched against paths in domain_substitution.list) that must keep their
# real Google endpoints, so the Google services we keep still work:
#   - Safe Browsing, standard mode
#   - the Widevine CDM download, via the component updater
#   - the Chrome Web Store: installing and updating extensions
# Check a change to this list by grepping the substituted tree for these services. fetch.sh stops
# when a line matches no file, so an upstream rename cannot silently drop an exclusion.
# At 157.0.8103.78: 77 of 17944 files excluded. This is broad: it also keeps the endpoints of
# real-time URL lookup, extension telemetry, incident reporting and client-side detection. Those are
# switched off by chromium/patches/safe-browsing-standard-only.patch (enhanced-only features,
# real-time lookups) and ungoogled's iridium patches (incident reporting). The list is broader than the hosts standard
# mode contacts; it can be narrowed once a network audit has confirmed which hosts those are.
^components/safe_browsing/
^chrome/browser/safe_browsing/
^components/component_updater/

# update.googleapis.com, set in component_updater_url_constants.cc; the component updater line
# above keeps it too, but the store needs it whether or not Widevine is built.
